# Welcome to Dr. Ahmed's Personal Website

This is the personal website of Dr. Ahmed Mohammed Ali, a consultant in Internal Medicine & Cardiology. The website is built using Vite, TypeScript, React, shadcn-ui, and Tailwind CSS.

## Project Structure

The project is structured as follows:

```
src/
├── assets/             # Static assets (images, etc.)
├── components/         # Reusable UI components
├── contexts/           # Global state management
├── data/               # Static data (blog posts, content, etc.)
├── hooks/              # Custom React hooks
├── lib/                # Utility functions
├── pages/              # Route-specific components
├── types/              # TypeScript types
├── App.tsx             # Main app component
├── main.tsx            # Entry point
├── index.css           # Global styles
